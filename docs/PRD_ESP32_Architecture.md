# HiLily ESP32 硬件端产品需求文档 (PRD)

## 1. 产品愿景 (Product Vision)
**HiLily** 是一款致力于用 AI 温暖晚年时光的桌面级智能陪伴设备。
ESP32 硬件端作为 HiLily 的“耳目口鼻”，其核心使命是将物理世界的视觉与听觉无损、极速地搬运至云端大脑，并在接收到云端回馈时，提供**极致拟真、不卡顿、带有物理情绪呈现**的视听反馈体验。

### 1.1 战略演进路线 (Roadmap)
- **Phase 1 (当前版本 - 流媒体透传器):**
  硬件端作为纯粹的流媒体搬运工，配合后端的“ASR -> LLM -> TTS”级联管道。不涉及复杂的本地语义识别引擎。核心攻坚点在：基于 Jitter Buffer 的弱网抗抖动播放，以及基于 FreeRTOS 的 100ms 级别按键打断（Barge-in）响应。
- **Phase 2 (未来探索 - 适配原生多模态):**
  在服务端整体迁移至 **Gemini 3.1 Pro** 或 **GPT-4o Realtime** 等端到端原生语音大模型时，**硬件端的代码、网络通信协议和缓冲逻辑不应做任何颠覆性修改**。这是因为我们在 Phase 1 中已经通过 WebSocket 的“文本指令+二进制纯净音频”双轨通道，完成了硬件层与 AI 语义层的彻底物理隔离。

## 2. 核心用户场景与体验目标 (User Scenarios)

### 2.1 丝滑的开机与状态指示 (Instant Status Feedback)
- **场景描述:** 老年用户插上电源或唤醒设备，期待立即获得视觉与听觉的安全感。
- **产品逻辑:**
  - 设备通电后，屏幕在 3 秒内点亮并显示本地默认表情（如打哈欠）。
  - 网络连接与服务器握手成功后，呼吸灯或表情必须给出明确反馈（如笑眼 + 绿色柔光）。
  - 若遇网络断开，需通过 UI 和本地预置的音频语音（如：“哎呀，我好像迷路了”）温和提示。

### 2.2 随时打断与重听 (Barge-in / 全双工)
- **场景描述:** 用户觉得 HiLily 说话太啰嗦，直接按下顶部物理按键（或唤醒词）打算重新提问。
- **产品逻辑:**
  - 硬件中断 (ISR) 被触发后，**必须在 100ms 内**清空本地的音频 RingBuffer，停止喇叭出声。
  - 立即向服务端发送 JSON 格式的 `start_dialogue` 强插指令。
  - 屏幕表情和灯带同步切回 `Listening` 状态，给予用户打断成功的正反馈。

### 2.3 居家弱网对抗体验 (Network Resilience)
- **场景描述:** 路由器距离远，或微波炉工作时对 2.4G Wi-Fi 产生干扰，导致云端下发的音频包出现抖动和积压。
- **产品逻辑:** 
  - 严禁出现“卡带式”的尖锐爆音。
  - 基于本地的 Jitter Buffer (环形缓冲队列)，必须接收并囤积足够数量（例如 200ms）的流式切片后，再开启 I2S DAC 功放。宁可整体起播延迟增加 200ms，也必须保证说话过程的平滑连续。

## 3. 核心功能模块 (Core Modules)

### 3.1 视听采集与播放 (Audio/Visual I/O)
- **端侧 AI 降噪 (ESP-SR):** 集成乐鑫 ESP-SR 框架，利用内置神经网络实现本地 VAD (纯人声检测) 和 "Hi Lily" 离线唤醒词识别。拦截一切非人声底噪与无唤醒意图的旁聊，严守云端 Token 成本。
- **全向拾音:** 驱动 INMP441 进行 16kHz PCM 单声道低底噪采集。
- **功放解码:** 驱动 MAX98357 芯片，接收并硬解码/软解码下行的音频切片。
- **屏幕渲染 (UI/UX):** 整合 LVGL 引擎，以至少 30 FPS 的帧率渲染动态眼睛/表情，同时在角落显示电池电量与 Wi-Fi 强度图标。

### 3.2 任务隔离与协同 (FreeRTOS RTOS)
- **任务防挂死:** `AudioTask`、`NetTask`、`UITask` 必须在独立线程运行。即使网络卡死，UI 屏幕也不能冻结，必须能正常播报本地的断网动画。
- **内存安全:** 严格监控任务栈(Stack)剩余空间，预防长时间开机导致的内存碎片或栈溢出 (Stack Overflow)。

## 4. 非功能性需求 (NFR)
1. **稳定性指标:** 设备需支持 7x24 小时连续运行，期间不可出现由于内存泄漏 (Memory Leak) 造成的无故重启 (Panic/Watchdog Reset)。
2. **功耗管理:** 当处于 `Idle` 状态超过 15 分钟且无充电输入时，需切断功放电源、降低屏幕背光并降低 CPU 频率以延长待机时间。
3. **OTA 易用性:** 支持后台静默下载固件，并在夜间闲时或用户确认后自动重启完成覆盖升级。
